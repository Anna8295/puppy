# Cord & Coat

"Opening soon" landing page for Cord & Coat, a small shop for dog leashes, bowls, and coats. Built with React, TypeScript, Tailwind, and Vite.

The hero features a scrubbable dog image sequence — move your cursor (desktop) to look around, or watch it blink on its own (phone).

**Live:** https://anna8295.github.io/puppy/

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Pushing to `main` deploys automatically to GitHub Pages via GitHub Actions.
